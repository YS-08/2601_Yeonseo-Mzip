# ZIP

## 실행 방법 (AI 검색이 가장 안정적으로 동작하는 방법)
1. `.env.example` 을 복사해 `.env` 로 이름을 바꾸고 `OPENAI_API_KEY=` 뒤에 본인 키를 넣습니다.
2. 이 폴더에서 터미널을 열고 `node server.js` 를 실행합니다. (Node 18 이상)
3. 브라우저에서 http://localhost:3000 을 엽니다.

키는 서버(.env)에만 있고 브라우저로 전달되지 않습니다.

## 서버 없이 쓰기
`index.html` 을 바로 열어도 동작합니다. 이때는 오른쪽 위 "AI 설정"에서 키를 입력하면 브라우저가 OpenAI에 직접 연결합니다.
다만 OpenAI가 브라우저 직접 호출을 막는 경우가 있어(CORS) 연결 테스트가 실패할 수 있습니다. 키를 입력하지 않으면 데모 모드로 동작합니다.
